# Shot Mate 网站交接 · 2026-10-16

## 本轮实现
- 产品统一使用 Shot Mate（两个英文单词），移除可见的分镜牛/小绘名称及女性头像。
- 透明 PNG 英文扁宽字标：public/shotmate/wordmark.png。内置 image_gen 生成，纯文字、去背景、无中文；这是栅格资产，不冒充矢量文件。提示词要求 SHOT MATE、扁宽粗体、上下切边、暖白字与朱红 O、透明背景。
- 主色 #2145FF，强调 #FF563B / #E6FF42，输入纸面 #F7F5EE，结果工作区 #111B38。
- src/main.jsx 调整首页结构、品牌、空态和入口；src/shotmate.css 为响应式布局与品牌覆盖层；cinema.css 和 storyboard.jsx 调整旧金色/橄榄色为蓝色体系。
- 首页照片沿用此前本项目 AI 视觉参考，标明“视觉参考 · AI 示意图 / 尚未生成你的分镜”，不属于模型返回结果。
- 保留 GPT/豆包配置、导入、自动估时、逐镜修改、审核、CSV/JSON 导出、故事板及可编辑机位图。

## 启动与验证
Node >=24。npm install；npm run build；npm start。默认 http://127.0.0.1:4318/。
本轮构建和 17 项现有测试通过（包含 mock model pipeline，不等于真实模型通过）。浏览器检查首页、选项、示例、故事板、机位图、分镜表、编辑抽屉与 GPT/豆包设置。
