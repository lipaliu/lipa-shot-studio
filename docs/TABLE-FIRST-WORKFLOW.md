# 分镜表优先与按需机位（2026-10-16）

默认进入分镜表。创建项目、打开历史项目和示例均重置到表格。文字拆镜阶段不再要求模型返回 blocking；历史已有机位保留。

每镜摄影栏提供机位入口。无机位时可单独调用文字模型规划，也可手动创建草图。`POST /api/projects/:id/shots/:shotId/blocking` 返回经过 blockingSchema 验证的俯视坐标；参考同场已有机位，未知空间须标注假设。该请求仅生成草案，不写入项目，不调用图片模型。

编辑面板支持拖动人物、摄影机、朝向、主光和已有道具；支持方向键与坐标输入。拖动结束且停止编辑 700ms 后，以现有 PATCH 镜头接口保存。保存失败保留草稿并提供重试/撤销；未保存时阻止切镜、筛选或离开编辑视图，并提示浏览器关闭风险。

`shared/blocking.js` 用同一逻辑生成前端预览与服务端摄影/轴线/主光同步段。重复调整替换旧的【机位同步】段，不重复堆积。保留原对白、表演、估时与运镜意图。服务端重新编译提示词，因此表格、故事板手记、复制提示词、CSV/JSON 导出使用同一份保存数据。图片生成请求也读取最新机位坐标。Docker 构建与运行阶段均须复制 shared 目录。

构图预览是简化二维示意，不是三维摄影模拟。已有生成/上传图片不随拖动重绘；需要用户在故事板主动重新生成。机位变化后相邻镜头仍需审核轴线、视线和表演连续性。当前沿用项目的单人编辑假设，没有多人并发冲突合并。

验证：34 项离线/模拟模型测试通过；浏览器用预写示例验证默认表格、键盘与鼠标拖动机位、自动保存与提示词同步。不调用真实付费文字或图片模型。首次真实机位生成的艺术质量仍待用实际剧本验收。
