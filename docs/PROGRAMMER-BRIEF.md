# 发给程序员 · Lipa 分镜工作台

源码：https://github.com/lipaliu/lipa-shot-studio （私有仓库，默认分支 codex/initial-delivery）

## 产品要求已定

页面尽量简单，只有两个主要窗口：**左边粘贴剧本 → 点「生成分镜」→ 右边直接出表格**。不要增加向导、让用户选择 Skill，或要求用户填写目标总时长。手机端按上下排列。

- 表格保留镜号、原文出处、画面、表演、景别/机位/运镜、正反打/轴线、美术/画风/光线、对白/环境声/音效/配乐、预计秒数和完整提示词。
- 时长由模型根据对白、动作、停顿逐镜估算，程序计算并汇总；用户可在镜头详情调整。
- 点镜号可修改、逐镜审核、复制提示词、导出表格。再次生成新建一份，旧结果保留在历史。
- 更多拍摄选项默认折叠，历史分镜和模型配置放顶部，主流程不需要填写这些。
- GPT 和豆包都支持，在后台切换。API Key 只放服务端。
- 主创作规则是随代码保存的 Higgsfield 社区 Skills（导演分镜、表演、摄影、风格、声音），由 GPT/豆包读取执行。不要再接 Higgsfield 付费 API，也不依赖 Codex。

## 你接手后完成的事

1. Node.js 24，运行 npm ci → npm run build → npm start；本地 http://127.0.0.1:4318/ 。不能双击 index.html 运行完整应用。
2. 配置实际 GPT、豆包 Key 和模型 ID，分别测试连接并用 examples/script.txt 真实拆镜，记录结果和调用成本。当前本地示例是手写数据，真实模型质量尚未验收。
3. 部署独立的正式托管网址，持久化 SQLite 数据、配置 HTTPS 和访问密码，确保不依赖这台 Mac 或 Codex。提供了 Dockerfile/compose，但容器与公网还需你实际验收。
4. 验证导入/生成/修改/审核/导出、重启后数据保留、未登录时 API 受保护。正式地址需无账号会话依赖地打开团队登录页；大陆/微信可达性单独测试。
